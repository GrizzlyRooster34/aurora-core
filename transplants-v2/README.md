## Transplant Workflow

### For Each System:

**1. Copy to Staging**
```bash
cp ~/seven-of-nine-core-clean/path/to/source.ts staging/
```

**2. Sanitize** (Manual editing required)
- Remove "Seven" identity references → "Aurora"
- Remove "Creator" bond logic → "User" partnership
- Remove canonical memories, trauma processing
- Generalize emotional states
- Update documentation

**3. Scan for Contamination**
```bash
tsx contamination-scan.ts staging/source.ts
```

**4. Fix Violations** (Repeat until clean)
- Address each violation reported
- Re-run scan
- Must achieve ✅ CLEAN status

**5. Move to Final Location**
```bash
mv staging/source.ts core/spark/SystemName.ts
```

**6. Update Manifest**
- Mark module as "SANITIZED"
- Record scan results in TRANSPLANT_MANIFEST_V2.md
- Update contamination table

**7. Final Validation**
```bash
tsx contamination-scan.ts core/spark/SystemName.ts
```
